# Nicholas Harrison — Right to Repair

Personal landing site for Nicholas Harrison, Right to Repair activist.
Static and dependency-free (Google Fonts aside); every page shares `styles.css`.

## Pages
- `index.html` — home: animated "hello" hero, featured carousel, work grid
- `mission.html` — mission statement
- `get-involved.html` · `repair-guides.html` · `legislation.html` · `repair-cafes.html` · `talks.html` · `writing.html`
