Local AI

Run large language models on your own machine. This page is the starting point: the original engine, the friendlier app that followed, and a short look at the wider set of tools built on that work.

llama.cpp Ollama Ecosystem

Came first March 2023[1]

llama.cpp

llama.cpp is the original open-source C/C++ engine for running large language models locally, in the GGUF format, on CPU and GPU. Georgi Gerganov started the project in March 2023. It is maintained by the ggml authors under the MIT licence[1][2], and it is the foundation a lot of later local-AI software builds on.

Followed June 2023[3]

Ollama

Ollama is a friendlier app and command-line tool for downloading and running models on your own hardware. Its official project lists llama.cpp — founded by Georgi Gerganov — as a supported backend[3], and it pins a llama.cpp source tree in its own build[5]. Ollama is also released under the MIT licence[4].

Wider set of tools

Ecosystem

A growing set of apps, bindings and servers build on llama.cpp, use its GGUF model format, or ship a fork of the engine. The examples below are ones whose own official docs or repositories say so. This is not a complete catalogue, and some of these tools also support other engines.

  • LM Studio — a desktop app that can run GGUF models with llama.cpp (and MLX on Apple Silicon)[7].
  • llama-cpp-python — Python bindings for llama.cpp, with an optional OpenAI-compatible server[8].
  • KoboldCpp — a single-package server that “builds off llama.cpp” and runs GGML and GGUF models[9].
  • GPT4All — a desktop app and Python SDK that run local GGUF models with a llama.cpp backend[10].
  • Jan — a desktop app that ships a built-in llama.cpp engine for local GGUF models[11].
  • LocalAI — a self-hosted OpenAI-compatible API that lists llama.cpp as one of its backends[12].
